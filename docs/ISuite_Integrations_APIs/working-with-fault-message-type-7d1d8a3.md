# Working with Fault Message Type

A fault message type is designed for application-specific errors that occur at the provider \(inbound side\) and that are reported back to the sender or persisted in monitoring.

> ### Note:  
> Availability of this feature depends upon the SAP Integration Suite service plan that you use. For more information about different service plans and their supported feature set, see SAP Note [2903776](https://launchpad.support.sap.com/#/notes/2903776).

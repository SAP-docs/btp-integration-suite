# Integration Scenarios

The Cloud Integration capability allows you to automate the migration of multiple integration scenarios using a two-phased approach:

-   **Extract**: In the Extract phase, data from the source system in analyzed and prepared. See [Extract](extract-084e6f2.md)
-   **Generate**: In the Generate phase, the extracted information is used to create corresponding integration flows and the dependent artifacts. See [Generate](generate-f9100ff.md)

The migration happens in asynchronous mode where you can check the migration status in the meantime.
